# Minerva Backend

data: [https://minerva-api.kevinwoodfield.com/api/library](https://minerva-api.kevinwoodfield.com/api/library)

## Get Started

Create virtual environment

```
python3 -m venv venv
```

Activate the virtual environment

```
source venv/bin/activate
```

Install Django

```
pip install django django-ninja
```

Install requirements

```
pip install -r requirements.txt
```

Run server

```
cd src && python3 manage.py runserver 8000
```
