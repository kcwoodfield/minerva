# Architecture Documentation

This directory contains system design documentation and technical architecture decisions for Minerva.

## Contents

### System Architecture
- **overview.md** - High-level system architecture and component relationships
- **database-design.md** - Database schema, models, and data flow
- **api-specification.md** - API design patterns and endpoint documentation

### Technical Decisions
- **technology-stack.md** - Rationale for Django, Next.js, and other tech choices
- **security-architecture.md** - Authentication, authorization, and security patterns
